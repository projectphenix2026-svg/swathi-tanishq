# swathi-tanishq

A WhatsApp and SMS messaging project for sending promotional, personalised and bulk messages.

## Requirements

1. Send promotional messages on WhatsApp.
2. Send dynamic, personalised messages through the WhatsApp API (for example, using the customer's name).
3. Add CTAs (call-to-action buttons) to WhatsApp API messages.
4. Send bulk SMS messages.
5. Personalise SMS messages.

## Files

- `index.html` – a starter page that lists the project requirements.
